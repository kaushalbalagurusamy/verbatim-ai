Cursor Column Preservation Test

To test the cursor column preservation fix in the Document editor:

  1. Open the Verbatim AI application in development mode
  2. Navigate to the Document view
  3. Create multiple paragraphs with varying lengths
  4. Place your cursor at a specific position in a paragraph (e.g., middle of a word)
  5. Use the ↑ and ↓ arrow keys to navigate between paragraphs
  6. The cursor should maintain its horizontal position (column) when moving vertically

Expected Behavior:

  • When moving UP/DOWN, cursor stays at the same character column
  • If the target line is shorter, cursor goes to the end of that line
  • Horizontal movement (LEFT/RIGHT arrows) or clicking resets the column tracking
  • Typing text also resets the column tracking

Test Scenarios:

1. Start here with cursor at position 20 → | ← then press DOWN

2. Short paragraph

3. This is a longer paragraph where the cursor should return to position 20

4. Another paragraph with wrapped text that spans multiple visual lines within the same block. When navigating here, the cursor should be placed on the first visual line at the saved column position.

Implementation Details:

The fix involves:

  • New utility: /src/utils/cursor-column-tracker.ts
  • Tracks both character offset and X coordinate for accuracy
  • Updates to arrow key handling in editor-handlers.ts
  • Clears saved position on horizontal movement, clicks, or typing
