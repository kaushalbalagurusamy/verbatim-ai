Test Instructions

1. Bold Formatting:
  • Select text and click Bold button or press Ctrl/Cmd+B

3. Minimize Formatting:
  • Select text and click Minimize button or press Ctrl/Cmd+M
  • Verify text appears smaller and dimmed

4. Clear Formatting:
  • Apply multiple formats to text

5. Heading Levels:
  • Place cursor in a line and click Heading button
  • Verify it cycles through H1-H6
