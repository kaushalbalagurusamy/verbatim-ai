# Bug Reproduction Documentation

This directory contains detailed reproduction steps and test cases for all reported editor bugs.

## Bug Categories

1. **Line Number Cursor Tracking** - Issues with line number highlighting not matching cursor position
2. **Selection Navigation** - Problems with keyboard shortcuts for text selection
3. **Line Spacing Alignment** - Line number and content alignment issues
4. **Multi-line Mouse Selection** - Mouse selection across paragraphs
5. **Highlight Color Functionality** - Color cycling and application issues

Each bug will have its own detailed documentation file with:
- Reproduction steps
- Expected behavior
- Actual behavior
- Test cases
- Fix verification steps
