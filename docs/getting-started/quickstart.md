# Quickstart Guide

Get up and running with Verbatim AI in just 5 minutes! This guide will walk you through the basics.

## Prerequisites

Before you begin, ensure you have:
- Node.js 20+ installed
- pnpm package manager (or npm/yarn)
- A modern web browser (Chrome, Firefox, Safari, or Edge)

## Quick Setup

### 1. Clone and Install (2 minutes)

```bash
# Clone the repository
git clone https://github.com/your-org/verbatim-ai.git
cd verbatim-ai

# Install dependencies
pnpm install
```

### 2. Start the Development Server (30 seconds)

```bash
# Start the application
pnpm dev
```

The application will start on http://localhost:8080

### 3. First Look (2 minutes)

When you open the application, you'll see three main areas:

#### Left Sidebar
- **File Tree**: Navigate your documents
- **Search**: Find files quickly
- **View Modes**: Switch between Document, Pen, Source, and Recording views

#### Center Editor
- **Tabs**: Work with multiple documents
- **Editor**: Full-featured text editing
- **Toolbar**: Quick access to formatting options

#### Right Chat Panel
- **AI Assistant**: Your intelligent helper
- **Context-Aware**: Understands your current document
- **Commands**: Natural language interactions

## Basic Usage Examples

### Creating Your First Document

1. **Click the "+" icon** in the file tree
2. **Name your document** (e.g., "my-first-note.md")
3. **Start typing** in the editor
4. **Save automatically** happens as you type

### Using AI Assistance

1. **Open the chat panel** (right side)
2. **Type a question** about your document:
   ```
   "Can you summarize the main points?"
   "Help me improve this paragraph"
   "What topics should I cover next?"
   ```
3. **Apply suggestions** with a single click

### Switching View Modes

Try different modes for different tasks:

- **Document View**: Writing and editing
- **Pen View**: Analytics and note-taking
- **Source View**: Managing references
- **Recording View**: Audio notes

Click the mode buttons in the sidebar to switch.

### Working with Multiple Files

1. **Open multiple files** by clicking them in the sidebar
2. **Switch between tabs** in the editor
3. **Drag tabs** to reorder them
4. **Close tabs** with the × button

## Quick Tips

### Keyboard Shortcuts
- `Ctrl/Cmd + S`: Save current document
- `Ctrl/Cmd + P`: Quick file search
- `Ctrl/Cmd + /`: Toggle chat panel
- `Ctrl/Cmd + B`: Toggle sidebar

### AI Commands
Start your chat messages with these for specific actions:
- `/summarize` - Get a summary of current document
- `/analyze` - Deep analysis of content
- `/suggest` - Get improvement suggestions
- `/explain` - Explain complex sections

### File Organization
- Use folders to group related documents
- Name files descriptively
- Use markdown for rich formatting
- Tag documents for easy searching

## Common Tasks

### Import Existing Documents
1. Drag and drop files into the file tree
2. Or use File → Import from the menu
3. Supports .txt, .md, .doc, and more

### Export Your Work
1. Right-click on any document
2. Select "Export as..."
3. Choose format (PDF, Word, Markdown)

### Collaborate with AI
1. Select text in the editor
2. Right-click and choose "Ask AI about this"
3. Get instant insights and suggestions
